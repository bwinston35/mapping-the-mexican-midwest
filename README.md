# mapping-the-mexican-midwest

This is the repository for the digital history project Mapping the Mexican Midwest.

To visit the digital history project, [follow this link](https://mappingthemexicanmidwest.bryanwinston.org).

The repository also contains maps in development.

## rail-communities

I am currently developing a map that illustrates Mexican placemaking in relation to railroads. This map is the file titled `rail-communities.html`. It uses a georeferenced 1903 map of the Atichson, Topeka and Santa Fe railroad. The 1903 map is from the [David Rumsey Map Collection](https://www.davidrumsey.com/).
